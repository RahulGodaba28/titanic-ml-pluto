# Titanic Survival Prediction — Pluto Academy AI/ML Internship

ML classification project predicting Titanic passenger survival using 3 models.

## Dataset
[Titanic — Machine Learning from Disaster (Kaggle)](https://www.kaggle.com/c/titanic)

## Tools Used
Python · Pandas · Scikit-learn · Matplotlib · Seaborn · Google Colab

## Models Trained
| Model | Accuracy | Precision | Recall | F1 Score |
|---|---|---|---|---|
| Logistic Regression | 0.7989 | 0.7797 | 0.6667 | 0.7188 |
| Random Forest | 0.8268 | 0.8065 | 0.7246 | 0.7634 |
| KNN (k=5) | 0.8101 | 0.7869 | 0.6957 | 0.7385 |

## Best Model
Random Forest — highest F1 Score. See confusion matrix and feature importance in notebook.

## How to Run
1. Open the `.ipynb` file in Google Colab
2. Upload `train.csv` from the Kaggle Titanic competition
3. Run all cells top to bottom
